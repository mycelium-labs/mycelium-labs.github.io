What you can run

Synthetic checks,
separate from these notes.

  • Mycelium does not publish a model-quality eval suite. Hallucination and goal alignment stay outside these runtime guards.
  • Doctor and Verify inspect configuration and exercise synthetic redispatch, crash, contention, and outage scenarios. They do not call application tools, models, or live providers.
  • Provider conformance challenges the Gmail adapter with lag, ambiguity, duplicate matches, malformed handles, and forbidden writes, then emits a signed report bound to the tested source. That report is not live-lane evidence.

Coding agents

There is a setup skill.

The repository ships $mycelium-setup. In a project, ask a coding agent to use it. It inventories tools, proposes side-effect classifications, fills mycelium.yaml, wires a supported runtime, and runs Doctor and Verify. You still approve consequential classifications, identity, secrets, and provider access.
