The AF-00N field guide

Know what you’re stopping.

Six production failures. Each one has a boundary, a record, and a refusal mode.

AF-002Duplicate side effectsA retry becomes a second real-world action.Durable claim; execute once; reconcile uncertainty. AF-003Infinite loopsThe agent repeats without making progress.Detect the action streak; stop the next step. AF-004Bad tool callsWrong input, entity, path, or return shape.Validate at the boundary before execution. AF-006Stale contextOld or malformed state becomes the truth.Protect messages, history, and session state. AF-007Early “done”The run declares success with work unresolved.Refuse completion until required outcomes exist. AF-008Scope creepA narrow grant silently widens mid-run.Freeze scope; reject transitive escalation.

Fits your stack

Your tools stay yours.

LangGraph · CrewAI · plain Python

Mycelium wraps the Python callable at the boundary. Supported integrations automate wiring; any Python tool can use the same ledger contract.

from mycelium import ledger_sync
from mycelium.transition import SideEffectClass, ToolTransitionBinding
binding = ToolTransitionBinding.for_tool(agent_id="payments",
  policy_version="v1", side_effect_class=SideEffectClass.KEYED_MUTATE)
@ledger_sync(transition_binding=binding)
def charge_customer(order_id, amount): return provider.charge(order_id, amount)
