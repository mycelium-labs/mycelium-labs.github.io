Fits your stack

Your agent stays yours.

Wrap Python callables directly, enable automatic LangGraph boundaries, or register adapters for a custom runtime.

LangGraphPlain PythonCustom runtimes

Configured guards are enforced only where their boundary or supported adapter is wired. Local protection must never be silently bypassed if the hosted control plane is down. Read the integration guide →

mycelium.yaml

integrations:
  langgraph:
    enabled: true

loop_guard:
  enabled: true
  missing_run_id_policy: error

completion:
  storage: file
  path: ./mycelium-completion.json
  required:
    - id: charge_customer
mycelium doctor --config mycelium.yamlREAD-ONLY CHECK
